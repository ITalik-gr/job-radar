# Ручні імпорти

Сюди кладуться дампи, які не можна тягнути автоматично.

- `clutch/`, сторінки каталогу Clutch, збережені з браузера як HTML.
  Обробка: `pnpm cli import:clutch ./imports/clutch/*.html` (Етап 6).
- CSV зі стовпцями `name,domain,country,note` приймається тим самим імпортером.

Вміст каталогу не комітиться, це локальні дані.
